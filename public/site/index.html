PERTANYAAN UMUM

Frequently Asked Questions

Semua hal yang perlu Anda ketahui tentang implementasi software, arsitektur data, dan layanan FINTEGRITA.

01 Apakah software FINTEGRITA bisa disesuaikan dengan SOP & AD/ART lembaga kami?
Bisa. Alur persetujuan (approval multilevel), skema bunga pinjaman (flat, efektif, menurun), biaya administrasi, hingga format pencetakan laporan RAT dikustomisasi secara presisi sesuai aturan main dan AD/ART lembaga Anda.
02 Apakah FINTEGRITA menyediakan server atau cloud hosting?
Tidak. FINTEGRITA berfokus murni pada rekayasa software dan edukasi akuntansi, sehingga kami tidak menyediakan server atau cloud hosting. Software dan database diinstal langsung di infrastruktur/server mandiri milik lembaga Anda (Private VPS, Cloud lembaga, atau Server On-Premise). Keunggulannya: kepemilikan dan kedaulatan data 100% mutlak milik lembaga Anda, tanpa risiko kebocoran di server bersama dan tanpa ketergantungan pihak ketiga. Tim kami siap membantu proses instalasi dan konfigurasi teknis hingga sistem siap digunakan.
03 Bagaimana FINTEGRITA menjamin keamanan dan kerahasiaan data lembaga?
Karena software berjalan di server privat milik lembaga Anda sendiri, database terisolasi total dan tidak bercampur dengan instansi lain. Sistem kami menerapkan standar keamanan ketat: enkripsi transmisi TLS 1.3 / AES-256, proteksi injeksi, serta audit log aktivitas transaksi yang tidak dapat dimanipulasi (immutable audit trail) sesuai standar kepatuhan akuntansi SAK.
04 Apakah bisa migrasi dari pembukuan Excel atau catatan fisik lama?
Bisa. Tim teknis FINTEGRITA mendampingi proses validasi dan impor data awal (daftar anggota, saldo simpanan, baki debit pinjaman berjalan, dan data produk) langsung dari format spreadsheet Excel ke dalam database sistem baru.
05 Apakah staf dan pengurus kami mendapatkan pelatihan langsung?
Ya. Paket implementasi sudah termasuk sesi pelatihan (onboarding) langsung bagi pengurus, bendahara, dan operator kasir. Kami juga menyediakan panduan video, modul SOP ringkas, serta dukungan konsultasi akuntansi berstandar SAK.
06 Berapa lama proses implementasi hingga sistem siap pakai (Go-Live)?
Untuk paket standar (Software Koperasi dan Website Profil), deployment dan setup awal di server mandiri lembaga Anda membutuhkan waktu 3–7 hari kerja setelah data siap. Untuk kebutuhan sistem custom enterprise berskala besar, rata-rata pengerjaan berkisar antara 2–4 minggu.
